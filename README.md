# Luxury Motors Colombia

Sitio web estático de lujo para exhibir y reservar vehículos BMW y MINI Cooper en Colombia.

## Secciones
- **Inicio:** video fullscreen con mensaje de bienvenida y modelos destacados.
- **Marketplace:** catálogo de vehículos disponibles con precio en pesos colombianos.
- **Detalles del vehículo:** galería, especificaciones y botón de reserva por $1.000.000 COP.

## Tecnologías
- HTML + TailwindCSS vía CDN
- Animaciones con [AOS](https://michalsnik.github.io/aos/)

## Uso
Abra `index.html` en un navegador para explorar la experiencia.
